FanDesk

A desktop CRM for people who run Fansly accounts. Add as many accounts as you need, sign in yourself, and keep a separate saved login for each one.

Not affiliated with Fansly or FBuddy.

Download for Mac Universal disk image · Apple silicon and Intel Download for Windows 64-bit installer

Downloads come from the public releases repository. The buttons use the latest assets FanDesk-mac-universal.dmg and FanDesk-windows-x64.exe.

What it does

  • Add a Fansly account with a label and username. FanDesk opens fansly.com in a sandboxed window for that account.
  • Each account has its own saved login, so several accounts can stay signed in at the same time. You type the password yourself. FanDesk never stores it.
  • Rename an account, switch from the left rail, or remove it. Removing an account clears that login from this computer.
  • Keep contacts, templates, smart lists, campaign drafts, and a media library for each account. Campaigns are drafts and previews only.
  • Add a starter pack of welcome, renewal, tip, and follow-up templates. Edit the wording. Placeholders such as {name}, {username}, and {tier} fill in from the contact.
  • Sort fans into folders such as Whales, Dolphins, Minnows, and Ghosts from the spend and dates you record. Rename them, change the thresholds, or pin someone by hand.
  • Write automation rules for a new follower, a subscriber, a renewal, a tip, a quiet subscriber, a birthday, or a scheduled note. Due messages wait in Ready to send. Copy opens that account’s Fansly chat with the text on your clipboard. FanDesk does not press Send.
  • Record earnings by hand or from a CSV, then see day, week, and month totals, source, top spenders, and new versus churned subscribers. Those figures are what you entered. They are not verified with Fansly.
  • Store photos and video as files on this computer, in albums, with tags and a used-on date. Image import strips EXIF and GPS unless you turn that off.
  • Export and restore a JSON backup of the records. Media bytes stay in the media folder beside that file. There is an optional fictional demo workspace if you want to look around first.

FanDesk does not scrape Fansly and does not send chat messages for you. Anything you do in the Fansly window happens on the real website. A per-rule auto-send switch only marks a rule; delivery stays a click you make.

Install an unsigned build

Mac

The universal disk image runs on Apple silicon and Intel. If macOS says the app is from an unidentified developer, right-click FanDesk and choose Open. If it is still blocked, open System Settings, go to Privacy & Security, and choose Open Anyway.

Windows

Run the installer. If SmartScreen appears, choose More info, then Run anyway. The installer is 64-bit only.

Signed and notarized builds do not need those steps. Signing is optional and stays off unless the release environment has a certificate. See the README for CSC_LINK, WIN_CSC_LINK, and the Apple notarization variables.

Privacy

All FanDesk data stays on your computer: contacts, notes, templates, drafts, earnings you recorded, and backups. Media files sit beside the workspace file. None of it is encrypted. Keep your own backups, and protect the computer. Removing an account deletes its local workspace, its media files, and its saved Fansly session. FanDesk never stores a Fansly password.

The optional DeepSeek draft helper is the exception. When you click AI draft, that message is sent to DeepSeek. The API key stays in a local file and is not included in workspace backups. FanDesk does not add a cloud account of its own.
