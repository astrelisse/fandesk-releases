# FanDesk downloads

FanDesk is a local-first desktop CRM for people who run Fansly creator accounts. You can add several accounts, each with its own saved login, and keep contacts, templates, automation reminders, earnings notes and a media library on your own computer.

This repository only hosts the installers and the download page. The source code lives in a separate private repository.

Website: https://astrelisse.github.io/fandesk-releases/

All versions: [Releases](https://github.com/astrelisse/fandesk-releases/releases)

## Installing an unsigned build

The builds are not code-signed unless stated in the release notes.

- **macOS:** open the disk image and drag FanDesk to Applications. If macOS says the app is from an unidentified developer, right-click FanDesk and choose **Open**. If it is still blocked, go to **System Settings → Privacy & Security** and choose **Open Anyway**.
- **Windows:** run the installer. If SmartScreen appears, choose **More info**, then **Run anyway**.

## Privacy

All FanDesk data stays on your computer and is not encrypted. Keep your own backups. FanDesk never stores your Fansly password.
